## 什么是"日本 VPS 原生 IP"，为什么它重要

**原生 IP（Native IP）** 指的是 IP 段本身在 ARIN 或 RIPE 等机构注册地址就归属该国，而不是通过 BGP 广播"借用"到那个区域的 IP 块。通俗说就是：IP 数据库里看到它，显示的就是日本，不会有"Relay""Proxy""Data Center"这类标注。

很多便宜的日本 VPS 用的其实是美国或香港 IP 段重新广播过去的地址，流媒体检测一查就露馅，Netflix、AbemaTV、DMM 该封的照封。

DMIT 东京机房全系标配原生日本 IPv4，这点在实测里一直保持稳定。不过流媒体的 IP 封禁名单是动态的，官方不做书面保证——买之前用测试 IP `154.12.190.32` 自己跑一遍 IP 属性检测是个好习惯。
